## Yopilgan gap'lar — ushbu commit

1. **Transitive `dependsOn` cycle detection** (`hr-task-template.service.ts:assertNoCycle`) — A→B→…→A chain'larni edit rejimda DFS bilan tekshiradi. MAX_DEPTH=64 defensive cap. **5 ta yangi test** (self, 2-hop, 3-hop, non-cyclic chain, missing parent).
2. **Optimistic concurrency lock** (`UpdateHrTaskTemplateSchema.expectedUpdatedAt`) — ixtiyoriy `expectedUpdatedAt` field; service `ConflictException` qaytaradi mismatch bo'lsa. Back-compat: omitted bo'lsa eski xulq. **3 ta yangi test.**
3. **Deadline cron tick overlap guard** (`HrDeadlineExpireService.running` flag) — keyingi tick in-flight bo'lsa skip + log. **2 ta yangi test** (overlap skip, exception releases flag).
4. **Telegram phone canonical normalization** (`hr-shared/phone-normalize.util.ts`) — Uzbek mobile/landline/foreign shapes canonical `+998XXXXXXXXX` ga. Employee create + update'da applied. **10 ta util test + 5 ta service test.**
5. **Money input hardening** (`template-modal.tsx:somToMinor`) — strip thousand separators (` `/`_`/`'`/`,`), reject negative, 15-digit int cap, clearer error messages.

**Test count delta:** 152 → **~177** (+25 adversarial tests).

## Accepted risks (open issues — Future sprint)

1. **Race window in `recordAnswer`** — 2 xodim parallel POST bilan (technically same employee). Mitigation: own_only filter + log.status check. Real-world likelihood: 0 (xodim 2 ta tab'da bir vaqtda submit qilmaydi). **Fix:** atomic `updateMany WHERE id=? AND status='sent'` shape, deferred to P6 hardening.
2. **Cron + manual dispatch duplicate** — yangibolim parity, admin UI'da ko'radi. Fix: partial unique index agar shikoyat bo'lsa.
3. **WS missed events on reconnect** — exponential backoff bor, lekin downtime davomida emitted event'lar yo'qoladi. Mitigation: tanstack-query polling fallback emas, lekin foydalanuvchi qo'lda refresh qila oladi. Fix: `?since=ts` replay (P6).
4. **JWT 15-min admin demote window** — standart access-token TTL trade-off. Fix: WS periodic re-verify (P6).
5. **Bootstrap catch-up** — API restart paytida missed scheduled cron ticks skipped. Fix: boot-time stale-log scan (P6).
6. **No focus trap in modals** — keyboard-only users ESC ishlaydi, lekin focus trap yo'q. Fix: switch to native `<dialog>` yoki radix-ui `Dialog` (P6 a11y polish).
7. **No load test** — 1000 template scheduler boot scan, 100 employee deadline tick, 50 concurrent WS. Performance unknown. Fix: dedicated benchmark suite (post-P4).
